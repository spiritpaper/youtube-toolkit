See how YouTube connects videos

Start from any video. The web shows the videos YouTube suggests next to it, then the ones suggested next to those. An arrow A → B means YouTube suggests B on A's page.

  • Hubs are videos YouTube suggests from many others. They're the center of this audience's journey.
  • Clusters are groups of connected videos on the same topic.
  • Click a video to see why it's connected, expand its own suggestions, or save it as an idea.

Suggestions are read from YouTube's pages for free. Scoring uses ~1 API unit per 50 videos plus ~5 per new channel. A new web usually costs 100–150 units.
